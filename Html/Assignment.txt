1. Explain the difference between frontend, backend, and full-stack development with
suitable real-world examples.
Frontend Development
Deals with the visual part of a website that users interact with — design, layout, and interactivity.
The Amazon homepage with buttons, search bar, product listings — built using HTML, CSS, JavaScript.
Backend Development
Handles the server-side logic, database operations, and API integration — the “behind-the-scenes” functionality.
When you log into Netflix, the backend checks your credentials in the database. Built using Node.js, Python (Django), Java (Spring Boot), etc.
Full-Stack Development
Involves both frontend and backend — the complete web application workflow.
A blogging website built entirely by one developer — frontend with React and backend with Express + MongoDB.

3. Describe how a browser requests and displays a web page from a web server.
1.User enters a URL (e.g., www.google.com).
2.DNS Lookup: Browser converts domain name to an IP address.
3.HTTP Request: Browser sends a request to the web server.
4.Server Processes Request: Finds the requested page or executes code.
5.Server Responds: Sends HTML, CSS, and JavaScript files.
6.Browser Rendering:
	a) HTML → Structure of the page
	b) CSS → Styles and colors
	c) JS → Interactivity
7.Page Displayed: Browser combines all and displays it visually.

5.Explain what a web server is and give examples of commonly used servers.
A web server is software (or hardware) that delivers web pages to clients upon request via HTTP/HTTPS.
Common Web Servers:
	Apache HTTP Server – Open-source, widely used.
	Nginx – High-performance, good for handling many requests.
	Microsoft IIS – Used on Windows servers.
	Node.js (Express.js) – Server-side JavaScript runtime.
	LiteSpeed – Optimized for speed and performance.
